Test veille

Page de test du mode BU. Elle note ce que l’iPhone signale quand on quitte l’appli.

  1. Verrouille le téléphone 10 secondes, puis reviens.
  2. Passe sur une autre appli 10 secondes, puis reviens.
  3. Fais-toi envoyer une notification, touche-la, puis reviens.
  4. Refais les trois essais avec « Son muet » activé.
